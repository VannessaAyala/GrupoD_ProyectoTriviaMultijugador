PASO 2: INTEGRACIÓN EN SERVIDOR Y RUTAS OAUTH
================================================================================
Objetivo: Integrar las rutas de Google OAuth y proteger el servidor.

1. CONFIGURACIÓN EN SERVIDOR (server.js):
   // Añade estas líneas al inicio (antes de las rutas)
   const session = require('express-session');
   const passport = require('passport');
   require('./config/passport');

   app.use(session({ secret: process.env.SESSION_SECRET || 'secreto', resave: false, saveUninitialized: true }));
   app.use(passport.initialize());
   app.use(passport.session());

2. CREACIÓN DE RUTAS (routes/authRoutes.js):
   const express = require('express');
   const passport = require('passport');
   const router = express.Router();

   router.get('/google', passport.authenticate('google', { scope: ['profile', 'email'] }));

   router.get('/google/callback', 
     passport.authenticate('google', { failureRedirect: '/login' }),
     (req, res) => res.redirect('/lobby')
   );

   router.get('/logout', (req, res) => {
     req.logout(() => res.redirect('/'));
   });

   module.exports = router;

3. COMMIT:
   git add server.js routes/authRoutes.js
   git commit -m "feat: implement google oauth routes and session management"
