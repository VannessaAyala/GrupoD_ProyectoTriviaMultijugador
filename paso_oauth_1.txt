PASO 1: CONFIGURACIÓN DE DEPENDENCIAS Y PASSPORT
================================================================================
Objetivo: Preparar el entorno para OAuth 2.0 (Google).

1. INSTALACIÓN DE DEPENDENCIAS:
   Ejecuta en la carpeta 'GrupoD_ProyectoTriviaMultijugador':
   npm install passport passport-google-oauth20 express-session --save

2. CREACIÓN DE CONFIGURACIÓN (config/passport.js):
   // Asegúrate de crear la carpeta 'config' primero
   const passport = require('passport');
   const GoogleStrategy = require('passport-google-oauth20').Strategy;

   passport.use(new GoogleStrategy({
       clientID: process.env.GOOGLE_CLIENT_ID,
       clientSecret: process.env.GOOGLE_CLIENT_SECRET,
       callbackURL: "/auth/google/callback"
     },
     (accessToken, refreshToken, profile, cb) => {
       // Lógica para buscar/crear jugador en DB
       return cb(null, profile);
     }
   ));

   passport.serializeUser((user, done) => done(null, user));
   passport.deserializeUser((obj, done) => done(null, obj));

3. COMMIT:
   git add package.json package-lock.json config/passport.js
   git commit -m "feat: setup OAuth dependencies and passport configuration"
